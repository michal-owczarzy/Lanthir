Monitoring webu každých 5 minut

Monitoring webu je automatická kontrola, jestli web běží a odpovídá. U Lanthiru probíhá každých 5 minut a při výpadku přijde okamžitá notifikace. Zároveň hlídáme, kdy vyprší SSL certifikát a doména. Monitoring je součástí správy webu od 399 Kč měsíčně.

Proč weby padají a jak pomáhá monitoring

Weby většinou nepadají ze dne na den. Výpadku obvykle předchází delší problém: blíží se konec platnosti certifikátu nebo domény, web se postupně zpomaluje nebo přestane fungovat formulář. Monitoring takové signály zachytí včas. A když už k výpadku dojde, víme přesně, kde chyba je, a umíme dobu výpadku výrazně zkrátit.

Automatické testy formulářů

V tarifu Komplex nekontrolujeme jen to, jestli se web načte. Automatický test pravidelně projde důležité cesty jako skutečný návštěvník, například odešle kontaktní formulář, a ověří, že fungují. Nestane se tak, že web běží, ale poptávky vám týdny nechodí.

Kdo za monitoringem stojí

Monitoring má na starosti zakladatel a CTO Lanthiru Ing. Michal Owczarzy, který se specializuje na monitoring a DevOps. Mezi jeho nástroje patří Zabbix, GitLab CI/CD a Kubernetes.

Slovníček pojmů

Uptime

SSL certifikát
Zajišťuje šifrované spojení (https). Když vyprší, prohlížeč návštěvníky varuje, že web není bezpečný, a většina z nich odejde.
Expirace domény
Když se doména včas neprodlouží, přestane fungovat web i e-maily na této doméně.
Syntetický test
Automatický scénář, který na webu pravidelně zopakuje kroky návštěvníka, například vyplnění formuláře, a ověří, že vedou k cíli.

Časté otázky

Jak často monitoring web kontroluje?

Každých 5 minut. Když web neodpovídá, přijde okamžitá notifikace.

Kolik monitoring stojí?

Monitoring je součástí správy webu. Tarif Základ za 399 Kč měsíčně obsahuje kontrolu dostupnosti, notifikace a hlídání SSL certifikátu a domény. Měření rychlosti přidává Plus za 899 Kč, automatické testy formulářů Komplex od 2 499 Kč měsíčně.

Co se stane, když web vypadne?

Přijde okamžitá notifikace a protože víme, kde chyba nastala, umíme dobu výpadku výrazně zkrátit. V tarifu Komplex garantujeme zahájení řešení do 2 hodin.

Hlídáte i SSL certifikát a doménu?

Ano, už v tarifu Základ. Víme dopředu, kdy certifikát a doména vyprší, takže web nespadne kvůli zapomenutému prodloužení.
